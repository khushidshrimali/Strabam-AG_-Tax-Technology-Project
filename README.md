# Strabam AG - VAT Analytics Project

## Project Overview
This project explores the application of data analytics and business intelligence to VAT-related analysis for Strabam AG. It combines data preparation and workflow automation in Alteryx with interactive reporting and visualisation in Power BI.

## Tools & Technologies
- **Alteryx Designer:** Data preparation, transformation, and workflow automation.
- **Microsoft Power BI:** Data visualisation, dashboard development, and interactive reporting.

## Project Deliverables
- Alteryx workflow files documenting the data preparation and processing steps.
- Power BI report (`.pbix`) containing the project's analytical visualisations.
- Supporting documentation and screenshots, where available.

## How to Review
1. Review the Alteryx workflow files to understand the data preparation and processing logic.
2. Open the Power BI `.pbix` file in Power BI Desktop to explore the report and its interactive visuals.
3. Refer to the screenshots or exported report included in this repository for a quick preview.

**Note:** Opening the native workflow and Power BI files may require the relevant software. Any data or screenshots shared publicly should be checked for confidentiality and permission to share.
